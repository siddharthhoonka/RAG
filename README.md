# RAG
Retrieval Augmented Generation performed on a document using a pre-trained LLM through an API. The app is deployed on Streamlit and accepts a document and text query to retrieve information from the user. The app uses Tesseract for OCR (to extract text from the pages), Langchain for invoking the chain pipeline, and a pre-trained model through the Groq API for efficient and low-latency inference.
